# Transformer：从一句话到一次回答

> 小明从图书馆借了一本书，读完后把它还了回去。

你知道这里的“它”指书，因为你把前后的线索联系起来了。

Transformer 的一个重要做法，就是让不同位置的相关信息结合起来。这份教程从这个小故事出发，把背景、内部计算、生成回答和训练过程连成一条完整的讲解。

**[阅读完整教程：《Transformer：从一句话到一次回答》](docs/Transformer-零基础学习指南.md)**

第一次阅读建议顺读主教程；需要完整矩阵推演或 Python 实验时，再按主题查阅[原理与计算参考](docs/Transformer-原理与计算参考.md)。主教程会在当前章节讲清理解所需的前提，参考文用于进一步计算和练习。

正文分为 19 章，按知识的先后依赖安排：为什么需要上下文 → AI、神经网络与 Transformer 的前身 → 文字怎样变成数字 → 注意力和内部计算 → 自回归生成与大语言模型 → 参数怎样训练 → 不同 Transformer 结构 → GPU → ChatGPT → Agent → Jev 结构化决策 → AGI。

每个专业术语在首次出现时附上解释。向量先从饮料的甜度、酸度记录讲起，再用两张坐标图逐步说明数字顺序、维度和负数的位置，并区分人工评分与模型学到的表示。Q、K、V 先完整走一遍“找资料学做番茄炒蛋”的过程，再对应到数字计算。矩阵乘法、多头结果汇合、FFN、归一化、候选分数、损失和一次参数更新，都在对应位置给出可以跟着算的小例子。

每章末尾配有“想一想与解答”：问题紧接本章内容，答案说明原因、计算过程和常见误解。两份文档均已补齐章末问答；[原理与计算参考](docs/Transformer-原理与计算参考.md)还给出完整算例、小实验及修改实验后的预期结果。

内容以 Transformer 为主，GPU 用来解释计算与存储需求，Kubernetes 只简短说明运行管理的联系。后半部分区分网络架构、模型、生成方式、聊天产品与执行任务的系统；Jev 一章依据公开接口说明分类、评分、概率和置信度，并解释它怎样作为 Agent 的评估组件。
