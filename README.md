# Transformer：从一句话到一次回答

> 小明从图书馆借了一本书，读完后把它还了回去。

你知道这里的“它”指书，因为你把前后的线索联系起来了。

Transformer 的一个重要做法，就是让不同位置的相关信息结合起来。这份教程从这个小故事出发，把背景、内部计算、生成回答和训练过程连成一条完整的讲解。

**[阅读完整教程：《Transformer：从一句话到一次回答》](docs/Transformer-零基础学习指南.md)**

正文按知识的先后依赖安排：为什么需要上下文 → 模型怎样学习 → 文字怎样变成数字 → 怎样结合相关信息 → 怎样逐步生成回答 → 参数怎样得到训练 → 不同 Transformer 结构怎样组合。

每个专业术语在首次出现时附上解释。比如，先完整走一遍“找资料学做番茄炒蛋”的过程，再逐个说明 Q、K、V 对应的用途，用只含两个数字的例子解释它们怎样产生、怎样参与计算，以及本次计算结果与训练参数的区别；讲到残差连接、归一化时，也在原处解释它们解决什么问题。

每章末尾配有“想一想与解答”：问题紧接本章内容，答案说明原因、计算过程和常见误解。两份文档均已补齐章末问答；[原理与计算参考](docs/Transformer-原理与计算参考.md)还给出完整算例、小实验及修改实验后的预期结果。

内容以 Transformer 为主，GPU 和 Kubernetes 在末尾简短说明联系。
