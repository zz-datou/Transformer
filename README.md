# 用一个故事，读懂 Transformer

> 小明从图书馆借了一本书，读完后把它还了回去。

你知道这里的“它”指书，因为你把前后的线索联系起来了。

Transformer 的一个重要做法，就是让不同位置的相关信息结合起来。这份教程从这个小故事出发，一步步解释它怎样处理文字、怎样帮助模型回答问题。
